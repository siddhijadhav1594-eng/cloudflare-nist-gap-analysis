# Cloudflare Security Gap Analysis (NIST CSF)

## Overview
An independent gap analysis of Cloudflare's publicly available Security 
Exhibit, mapped against the NIST Cybersecurity Framework's five core 
functions (Identify, Protect, Detect, Respond, Recover).

## Why I did this
To build practical GRC (Governance, Risk, Compliance) skills by practicing 
how public security documentation is evaluated against an industry 
framework — a core task in real GRC analyst work.

## Method
1. Reviewed Cloudflare's public Security Exhibit and Trust Hub
2. Categorized each security statement into the 5 NIST CSF functions
3. Identified documentation gaps — areas where detail was limited or vague
4. Wrote actionable recommendations for each gap

## Key Finding
Cloudflare's public documentation is strong on Identify and Protect, but 
provides limited detail on Detect, Respond, and Recover — particularly 
around specific timeframes and testing methodology.
